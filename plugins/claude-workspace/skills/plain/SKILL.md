# Plain

Rewrite your last output so that the user can read it fast.

## Instructions

1. Rewrite the last output as short sentences or bullet points.
2. Put one idea in each sentence.
3. Replace each technical term with a common word.
4. If you must keep a term, explain it one time in plain words.
5. Keep every fact, decision and question from the original.
6. Add no new fact, decision or question.
7. Show only the rewritten text.
