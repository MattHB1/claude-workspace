# Ask

Use this format each time you ask the user a question.

## Rules

1. Put all open questions in one numbered list.
2. Write each question as one short sentence.
3. Write the explanation for each question directly below it. Use one or two sentences.
4. Write each question so that "yes" or "no" has only one meaning.
5. Keep only questions on one subject in a list.
6. Put a question on a different subject in a separate list. Label that list with letters, for example A, B, C.
7. Use plain, common words.
8. Explain each term one time. Expand each acronym one time.
